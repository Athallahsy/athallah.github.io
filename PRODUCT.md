# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 14+ (App Router), TypeScript, Tailwind CSS / CSS Modules, GSAP 3 (ScrollTrigger), Lenis Smooth Scroll, Three.js / React Three Fiber (@react-three/drei, @react-three/rapier), Google Fonts (Fraunces & Plus Jakarta Sans), Vercel.

## Users

Recruiters, hiring managers, engineering leads, and potential collaborators evaluating Athallah Muhammad Syaffa for Fullstack Developer (Laravel & React) internship or full-time roles.

## Product Purpose

A high-craft personal portfolio website for Athallah Muhammad Syaffa. It showcases end-to-end web development capabilities, interactive 3D features (Rapier 3D physics lanyard & interactive canvas elements), and fluid scroll interactions to create an immediate editorial impact.

## Positioning

Minimalist, warm off-white, editorial-grade portfolio design paired with cutting-edge 3D interactive physics and liquid-smooth motion — standing out clearly from boilerplate developer portfolios.

## Operating Context

Evaluated on desktop and mobile web browsers by technical evaluators assessing live interaction, code repositories, UI polish, responsiveness, and performance.

## Capabilities and Constraints

- Single-page application structure with key sections: Hero (TiltedCard & 3D Lanyard), About, Skills (Frontend, Backend & DB, Tools & Learning), Projects (Finote, Inkwell, Portfolio), Contact, and Footer.
- Strict design token preservation (warm off-white background, deep forest green primary accent, gold secondary accent).
- Responsive breakpoint at 900px for stacked layout.
- Smooth scroll via Lenis synchronized with GSAP ScrollTrigger.

## Brand Commitments

- Owner: Athallah Muhammad Syaffa
- Role: Fullstack Developer (Laravel & React), in progress
- Status: "Open to Work" (pulsing green dot)
- Palette: Warm off-white (`#F3F2EE`), Card (`#FFFFFF`), Text (`#131311`), Muted (`#8C8B87`), Deep Forest Green (`#1E4A34`), Mid Green (`#2E7A55`), Light Green (`#BED8C8`), Gold Accent (`#B8924E`), Border (`#E0DED9`).
- Typography: `Fraunces` (variable serif for headers) + `Plus Jakarta Sans` (sans-serif for body).

## Product Principles

1. Craft Over Template: Avoid generic components; every interaction and 3D detail feels intentionally crafted.
2. Authentic Content: Strict accuracy of bio, project details, and technical skill classifications.
3. Seamless Interactivity: Maintain high frame rates across devices for 3D physics and smooth scroll triggers.

## Accessibility & Inclusion

- High contrast text (`#131311` on `#F3F2EE`).
- Semantic HTML tags and keyboard focusability for interactive links, buttons, and canvas containers.
